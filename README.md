# Pixel Blaster

使用 HTML5 Canvas、CSS 與原生 JavaScript 製作的原創像素風橫向闖關遊戲。主角、怪物、地景與特效由 Canvas 繪製。

## 開始遊玩

[在 GitHub Pages 遊玩](https://james99ii67-hub.github.io/pixel-blaster/) · [在 Sites 遊玩或使用 ChatGPT 登入](https://pixel-blaster.koujames9845.chatgpt.site/)。也可以把 `index.html`、`style.css` 和 `game.js` 放在同一資料夾，從瀏覽器開啟 `index.html`。若要用本機 HTTP 伺服器，在專案資料夾執行 `python3 -m http.server 4173 --bind 127.0.0.1`，再開啟 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

## 語言

在設定的「語言 / Language / 言語」可選擇繁體中文、English 或日本語。首次選角畫面也有語言選單。切換會立即生效，重新開啟時會沿用同一瀏覽器上次的選擇。

## 操作

| 動作 | 鍵盤 | 手機與平板 |
| --- | --- | --- |
| 左右移動 | ← / → 或 A / D | 左側方向鍵 |
| 跳躍 | Space、↑ 或 W | 跳躍 |
| 朝面向方向連射 | 按住 X 或 J | 按住發射 |
| 必殺技 | L | 點「必殺技」 |
| 領域展開 | K | 點技能按鈕 |
| 切換武器 | 1–6 | 點目前武器的「切換」，再選已解鎖武器 |
| 重新開始 | R，再確認 | 右上角設定 → 重新開始，再確認 |

手機直向時，左右方向鍵與跳躍、射擊鍵分別在畫面下方兩側。手機與平板橫向時，16:9 畫面會放大，半透明操作鍵貼近左右拇指。可三指同時移動、跳躍及持續射擊。設定與武器清單開啟時暫停遊戲，關閉後繼續。

## 角色與領域展開

開始前可選星界術師或赤刃咒師。設定中的「更換角色」可隨時切換，角色與冒險進度分開保存。

通過暮光菇林後，兩位角色共用領域解鎖。星界術師的「無限星界」會停止附近敵人的行動、造成持續傷害，並將 Boss 出招節奏減慢 50%。赤刃咒師的「赤刃神殿」每半秒斬擊附近敵人，對 Boss 的傷害較低，並將出招節奏減慢 25%。兩種領域都持續 4 秒，Boss 的血條旁會顯示減速幅度。領域傷害遵守 Boss 的核心與無敵判定。

施放即開始共用的 60 秒冷卻。暫停會凍結倒數，更換角色會保留目前領域與剩餘冷卻。舊版第三至第五關存檔可直接使用技能。

## 必殺技

星界術師的「虛空・紫星」會發射穿透能量球。赤刃咒師的「次元斷界」會立即斬擊前方 450 × 144 的範圍（遊戲座標）。兩招從開局可用，命中各造成 60 點傷害，足以擊敗剩一半生命的星砂守護者，每名敵人每次施放最多受到一次傷害，Boss 核心防禦照常生效。

按 L 或點「必殺技」蓄力 5 秒，蓄力期間移動速度減半，普通武器暫停射擊。施放後冷卻 120 秒。蓄力時受傷、換角、離開關卡或重新整理會中斷，進入 15 秒短冷卻。冷卻會隨進度儲存，設定選單開啟時暫停計時。

## 解鎖武器

開局只有彩虹彈。看到補給磚時，站在它下方跳起頂撞，可解鎖並立即裝備新武器。之後可用數字鍵或畫面按鈕切換已解鎖的武器。

| 按鍵 | 武器 | 取得方式與效果 |
| --- | --- | --- |
| 1 | 彩虹彈 | 開局配備，穩定連射 |
| 2 | 星花散彈 | 第一關補給磚，扇形掃射 |
| 3 | 晶光穿透槍 | 第三關補給磚，高傷害，最多命中三個目標 |
| 4 | 閃電槍 | 第五關最後一道缺口後、魔王區入口前的紫色神器磚，按住可持續放電，最多同時電擊五隻怪物，每次脈衝對每隻造成 2.5 點傷害 |
| 5 | 噴火槍 | 第二關補給磚，快速噴火，射程約 78 遊戲像素 |
| 6 | 火焰雷射槍 | 第三關最後一道缺口後的橘色神器磚，按住發射可持續灼燒直線上的多個怪物 |

## 關卡

1. **晴光草原** · 巡邏史萊姆和草地平台。
2. **暮光菇林** · 跳跳兔和上下盤旋的蝙蝠。
3. **星砂晶谷** · 裝甲甲蟲、晶術師與 120 HP 的星砂守護者。靠近終點時守護者會甦醒，使出追蹤晶彈、斜晶星陣與雙重地鳴。擊敗守護者即可解開終點封印。
4. **霜風高地** · 冰盾騎士舉盾時會擋下正面射擊。霜靈在空中移動並發射三向冰彈。
5. **熔火遺跡** · 熔岩獵犬蓄力後會加速衝刺。熔核巨像擁有 180 點生命。第一階段可持續攻擊。降至 90 點時巨像暴走，須在熔雨與地波或星環攻勢後，趁青綠核心露出的 2.15 秒集中火力。核心關閉時會擋下六種武器及領域傷害。

每關抵達右方旗幟即可通關。按「下一關」會保留分數和武器，並恢復一點生命，最高三點。任何一關失敗後，點「重試本關」即可從該關起點滿血重試。分數回到進關時的數值，已解鎖的武器保留。碰到怪物、敵方彈或掉落地圖都會扣血。擊倒怪物有不同分值，收集晶石每顆得 25 分。

## 專案結構

- `index.html` 包含遊戲畫布、狀態面板和操作按鈕。
- `style.css` 定義像素畫布縮放、介面和觸控版面。
- `game.js` 包含關卡資料、輸入、物理、武器、敵人、計分和繪圖。

## 帳號與測試

GitHub Pages 提供訪客遊玩模式。Sites 版支援 ChatGPT 登入。遊戲設定中的「使用 ChatGPT 登入」會帶你前往登入頁。一般帳號與訪客皆依闖關進度取得武器。站主指定的測試帳號登入後，開局即擁有六把武器，可在「測試關卡」選擇五個關卡。選關會從該關起點以滿血、零分開始。登出後回到訪客模式。

測試帳號可在設定中獨立切換「無敵」、「領域無冷卻」和「必殺技無冷卻」。無敵時受擊與掉落皆不扣血，掉落會回到檢查點。領域無冷卻可在已解鎖的關卡反覆施放，每次領域結束後即可再用。關閉時恢復最近一次施放的冷卻。必殺技無冷卻時仍需蓄力 5 秒，施放或中斷後可立即重新蓄力。關閉時恢復最近一次施放或中斷的剩餘冷卻。測試開關在重新載入後回到關閉。

部署時以 Sites 的伺服器端秘密設定 `PIXEL_TESTER_EMAIL` 指定測試帳號的 ChatGPT 電子郵件。`worker.mjs` 讀取 Sites 驗證的訪客身分，使用 `node build-worker.mjs` 建置。直接開啟本機 HTML 時可玩訪客模式。

遊戲使用 Web Audio 即時合成像素風音效。首次按下操作鍵或觸碰遊戲按鈕後啟用。設定中的「♪ 音效開／關」可切換靜音，此設定會儲存在目前的瀏覽器。

五個關卡各有一段八小節的原創循環配樂，進入第五關魔王競技場會切換成戰鬥曲。點遊戲畫面、觸碰操作按鈕或按操作鍵後開始播放。「♫ 音樂開／關」與音效分別記憶。切到其他分頁時會暫停，結算時讓過關或失敗音效收尾。


## 引導、續玩與畫面

初次遊玩會看到四步新手引導，可隨時跳過，也可從設定再次開啟。手機直向時鏡頭放大並跟隨角色，進入魔王競技場時顯示完整彈幕。生命值下方的小條顯示本關距離終點的進度。

關卡、最近地面檢查點、生命、分數、已解鎖及裝備的武器、已收集晶石與已擊敗敵人會自動儲存。再次開啟時按「繼續遊戲」回到檢查點，仍存活的敵人會重新出場。抵達旗幟便記錄下一關；全破後可重玩第五關。最高分可在設定查看，從頭開始也會保留。

紀錄只保存在目前網站與瀏覽器的 localStorage。一般遊玩與測試模式分開記錄，儲存內容不含電子郵件、登入憑證或其他帳號識別資料。GitHub Pages 與 Sites 各自保存進度。
